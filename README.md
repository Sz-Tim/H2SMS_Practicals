# H2SMS_Practicals

This repo contains the practicals for H2 Statistics for Marine Science. 

It is formatted as a quarto book and hosted online.

## Project profiles

The project is set up with three profiles: `man`, `key`, and `keyfull`. 

The file `_quarto.yml` controls global options, with the profile-specific options specified in `_quarto-man.yml`, `_quarto-key.yml`, and `_quarto-keyfull.yml`.

The manual and key can be re-rendered and published by running

> bash publish_man.sh

> bash publish_key.sh

> bash publish_keyfull.sh

The contents of the key (`_quarto-key.yml`) should be updated session by session throughout the semester as solutions are made available.
