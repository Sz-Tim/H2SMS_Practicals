1  Visualization

Statistics can be divided into two broad categories: descriptive statistics, which describe or summarise data, and inferential statistics, which allow us to infer something about a population from a sample.

This session focuses on descriptive statistics: how to appropriately display and summarise. You already know several techniques for displaying data (e.g., bar charts, histograms, scatter plots). When and how to use these techniques is one focus of today.

There are two critical purposes of data visualization:

  1. Getting a ‘gut’ feel for your data. Examining data graphically enables you to identify any outliers (suspicious observations which could be errors). It will also help you to select the most appropriate inferential statistical model (more on this later).
  2. Communicating your results. Focus on clarity, drawing attention to the most interesting aspects of your data. Graphics that are confusing, either through a lack of detail (e.g. no labels) or that contain too much information will fail in this central objective.

As you create graphics, keep in mind that they may be viewed on different machines, in grey scale, or by colour-blind or visually impaired readers. Colour scales such as those available from ColorBrewer or viridis are designed with this in mind.

1.2.1 Object structure

We will mostly work with dataframes. A data.frame is a 2D rectangular object with columns and rows. In a tidy dataset, each row represents an ‘observation’ and each column represents a ‘variable’. R (and often packages) contains several built-in dataframes, bundled into the datasets package which is automatically loaded.

1.2.3 NAs and summary

When you import data, you should check for missing values. These are represented as NA.

We can check each element of a vector using is.na(), which will return TRUE if an element is NA, and FALSE if an element is not NA.

is.na(penguins_alt$sex)

1.3 Graphical methods for displaying data

Always keep in mind that the primary reason for data visualization is to communicate concisely and accurately to your reader. Graphics should be clear, concise and easy to understand.

Real data is usually complex, and creating effective figures takes careful thought and often many revisions.

We will primarily use the ggplot2 package because it is more straightforward in many ways. It loads when you run library(tidyverse). However, we will also note equivalent base R functions from time to time.

1.3.1 Scatter plots

Scatter plots display two continuous variables against each other. They are commonly used for analyses like correlation or linear regression.

With ggplot2:

ggplot(penguins_alt, aes(x=body_mass, y=bill_len)) + 
  geom_point() + 
  labs(x="Body mass (g)", 
       y="Bill length (mm)",
       title="Bill length increases with body mass")

The ggplot() function takes the dataframe as the first argument. The plot aesthetics are specified with aes(), such that variables (=columns) are mapped to plot aesthetics. Then, layers are added using geom_*(). Additional functions can be ‘added’ to further modify the plot. See a comprehensive list in the ggplot2 manual.

Once you understand the basic structure, it becomes easy to create more interesting figures:

ggplot(penguins_alt, aes(x=body_mass, y=bill_len, colour=species_name)) + 
  geom_point() + 
  geom_line(stat="smooth", method="lm") +
  scale_colour_brewer("Species", palette="Dark2") +
  labs(x="Body mass (g)", 
       y="Bill length (mm)",
       title="Bill length increases with body mass")

With base R, the plot() function will create a scatter plot if given two numeric variables. There are two options for specifying the variables.

Using data_df with columns x and y, the same plot can be created with either syntax:

data_df <- data.frame(x=1:3, y=4:6)
plot(data_df$x, data_df$y) # two vectors: x, y
plot(y ~ x, data=data_df) # columns in dataframe: formula y ~ x

There are many options for modifying the output of plot(), but it is clunkier compared to ggplot2.

1.3.3 Line plots

Line plots are most often seen in timeseries plots with time on the x-axis and the response on the y-axis. Line plots involve joining points with a line, which indicates that you have made assumptions about the value of the response variable between successive measurements.

We will examine these plots using the dataset lynx, which consists of the number of Canadian lynx pelts sold per year between 1821 - 1934. It is a ‘classic’ dataset as it shows a cyclical ‘boom-and-bust’ lynx population (demonstrating predator-prey interactions).

First, we will create a variable Year.

1.3.4 Histograms

Histograms illustrate the distribution of continuous data. In histograms the bars are adjacent (no gap). This indicates that the underlying values are continuous rather than discrete.

ggplot(lynx_df, aes(Trappings)) + # specify x-axis, bun not y-axis
  geom_histogram(colour="grey30", fill="grey90") + 
  labs(x="Trapped lynx per year", 
       title="Lynx trapping")

1.3.5 Bar graphs

Bar graphs are used to plot counts of categorical or discrete variables. We’ll be using the islands dataset which is a named vector of island areas.

Many objects in R can have row names. However, converting between data types may lose this information. Consequently, it is better practice to store relevant information in a column. Nevertheless, there are occasions where this is useful and you may come across datasets with data stored as row names.

Working with data involves a lot of time spent tidying the datasets: cleaning, checking, and reshaping into useful formats. We will cover a more modern set of methods for this later in the course using the tidyverse package. For now, we’ll stay with base R. First, we need to tidy the islands data.

str(islands) # this is a named numeric vector
head(islands)

# convert to a dataframe
islands_df <- as.data.frame(islands) 
head(islands_df, 2)
str(islands_df) # rownames are not shown!
# put the row names into a new column
islands_df$LandMass <- row.names(islands_df) 
head(islands_df, 2)
           islands   LandMass
Africa       11506     Africa
Antarctica    5500 Antarctica
# set row names to the row number
row.names(islands_df) <- 1:nrow(islands_df) 
names(islands_df)[1] <- "Area" 
head(islands_df, 2) 
   Area   LandMass
1 11506     Africa
2  5500 Antarctica

An initial attempt at a barplot makes a terrible figure.

ggplot(islands_df, aes(LandMass, Area)) + 
  geom_bar(stat="identity") # 'identity' means it won't calculate any summaries

The whole dataset includes a lot of very small areas, so let’s cut it down to just the 10 largest. We also want to order the land masses by area in our plot.

We will use the arrange() function to order our dataframe, and then use scale_x_discrete() to specify the breaks in the desired order.

islands_df <- arrange(islands_df, desc(Area)) # desc() makes it largest to smallest
ggplot(islands_df[1:10,], aes(LandMass, Area)) + 
  geom_bar(stat="identity") +
  scale_x_discrete(limits=unique(islands_df$LandMass)[1:10])

It would be more effective sideways:

ggplot(islands_df[1:10,], aes(Area, LandMass)) + 
  geom_bar(stat="identity") +
  scale_y_discrete(limits=unique(islands_df$LandMass)[10:1]) +
  labs(x="Land mass", 
       y="Area (km^2)")

Data visualization is an iterative process with lots of trial and error to find a plot that communicates the message within the data well.

1.4 Summary statistics

You will often need to summarise your data before you present it. Data summaries are usually contained in tables and they can sometimes replace graphics (e.g., where the data is relatively simple or where individual precise values are important). There are many types of summary statistics. Here we are concerned with central tendency and variability.

Q. 1.9

What are the three main measures of central tendency?

Mean, median, and mode

Q. 1.10

What are three measures of variability?

Range, interquartile range (IQR), and variance / standard deviation

The most appropriate metrics of central tendency or variability will depend on your data. Another summary statistic that you might include is sample size. R is very good at producing summary statistics, and there are myriad ways to produce them.

Often you’ll wish to summarise your data across levels of a certain factor, such as levels of a certain treatment. More complex summaries can be made using the dplyr package. We’ll go into more detail later on some of the very powerful ways this package (and others in the tidyverse) can be used.

We’ll use the built-in dataset InsectSprays. Viewing your raw data can be an important check as well. You can open a spreadsheet-style viewer in R using View(YourDataFrame) or by clicking on the icon in the Environment pane.

str(InsectSprays)

To do more complex summaries, we will string together a series of functions. This can be done in a nested format (e.g., fun3(fun2(fun1(dataset)))), but this gets unwieldy very quickly.

So, let’s use the pipe operator |>. This takes the output from one function and feeds it as the first input of the next (e.g., dataset |> fun1() |> fun2() |> fun3()), making code much more legible. Many functions in the tidyverse are built for piping.

# use group_by() with the grouping column name(s)
spray_summaries <- InsectSprays |>
  group_by(spray) |>
  summarise(count_mean=mean(count))

1.5 Conclusions

Visualizing and summarising data are the critical first steps in the data analysis and reporting workflow. We use graphical methods to firstly explore our own data. Once we have made sense of it we select the most appropriate method to convey that understanding to our readers. We may help that communication by summarising data in the most appropriate way taking into account the distribution of the data and the presence of outliers.
